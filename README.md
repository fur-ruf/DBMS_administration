# Администрирование СУБД PostgreSQL (учебный проект, ИТМО)

## Что было сделано?

- Инициализировала и конфигурировала кластер PostgreSQL 16 (кодировка UTF8, локаль ru_RU.utf8, настройка postgresql.conf и pg_hba.conf под OLAP-нагрузку).
- Настраивала аутентификацию (peer для Unix-сокета, scram-sha-256 для TCP/IP), порты, параметры памяти (shared_buffers, work_mem, temp_buffers), журналирование контрольных точек и подключений.
- Создавала табличные пространства, базы данных и роли, выдавала права доступа; наполняла БД тестовыми данными от имени непривилегированной роли.
- Писала SQL-запросы для создания таблиц, вставки и выборки данных (CREATE TABLE, INSERT...SELECT, generate_series, агрегация, соединения).
